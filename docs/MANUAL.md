# DesignPoke 사용 매뉴얼

바이브 코딩 중 페이지의 버튼·글자·색·여백을 직접 만져 보고, 그 변경 의도를 AI 코딩 도구에 붙여넣을 수 있게 복사해 주는 크롬 확장입니다.

## 1. 설치와 실행

1. `chrome://extensions` → 개발자 모드 켜기 → "압축해제된 확장 프로그램을 로드합니다" → `extension/` 폴더 선택.
2. 아무 페이지에서 툴바 아이콘을 누르거나 `Ctrl+Shift+D`(Mac `Cmd+Shift+D`)로 켜고 끕니다.
3. 코드를 고쳤다면 `npm run build:ext` 후 확장 페이지에서 새로고침.

`chrome://`, `edge://`, 웹스토어 같은 특수 페이지에는 주입되지 않습니다.

## 2. 기본 흐름

1. **선택**: 요소를 클릭합니다. `Shift+클릭`으로 여러 개 선택, `Esc`로 해제.
2. **조정**: 드래그·핸들·방향키·오른쪽 속성 패널·텍스트 툴바로 바꿉니다.
3. **메모(선택)**: `Ctrl+K`로 "더 눈에 띄게" 같은 의도를 한 줄 적습니다.
4. **복사**: 오른쪽 패널 헤더의 **AI로 복사** 버튼(또는 `c`)을 누르면 변경 내용이 프롬프트 형식으로 클립보드에 들어갑니다.
5. **붙여넣기**: Claude Code 등 AI 채팅에 붙여넣습니다. 픽셀값은 AI가 프로젝트 스타일 시스템에 맞게 변환하도록 지시문이 포함됩니다.

## 3. 선택

| 동작 | 방법 |
| --- | --- |
| 하나 선택 | 클릭 |
| 여러 개 선택 / 해제 | `Shift+클릭` |
| 부모 / 자식으로 이동 | `Alt+휠`(위: 부모, 아래: 자식), `Shift+'`(부모), `Enter`(자식), `Shift+Enter`(부모) |
| 형제로 이동 | `Tab` / `Shift+Tab` |
| 같은 종류 모두 선택 | `Ctrl+E`(다음 하나), `Ctrl+Shift+E`(전부) |
| 자식 전부 선택 | `Ctrl+Shift+Enter` |
| 선택 해제 | `Esc` (선택이 없으면 DesignPoke가 꺼짐) |
| 식별자만 복사 | `Ctrl+클릭` (요소 이름을 클립보드에) |
| 핸들 숨기기 / 보이기 | `Shift+H` |

선택하면 분홍 테두리와 8개의 크기 조절 점, 이름 라벨이 뜹니다. 30px보다 작은 요소는 핸들이 자동으로 숨겨집니다.

선택은 값을 바꾸거나 되돌려도 유지됩니다. 해제는 `Esc` 또는 빈 곳 클릭뿐입니다. React 같은 프레임워크가 요소를 다시 그려 노드가 바뀌어도 같은 자리의 새 노드를 자동으로 다시 선택합니다.

## 4. 이동과 크기 조절 (기본 도구 "선택 / 이동", `l`)

| 동작 | 방법 |
| --- | --- |
| 이동 | 선택한 요소를 드래그 (5px 이상 움직여야 이동으로 인식) |
| 완전히 자유롭게 이동 | `Shift+드래그` (absolute 전환, 다른 요소에 영향 없음) |
| 미세 이동 | `←↑↓→` 1px, `Shift+방향키` 10px |
| 크기 조절 | 모서리·가장자리 점 드래그 |
| 비율 유지 | 모서리 점은 기본으로 비율 유지 |
| 자유 비율 | `Shift+드래그` |
| 중심 기준으로 늘리기 | `Alt+드래그` |
| 자식까지 함께 배율 조절 | `Shift+Alt+드래그` (transform scale) |
| 복제 | `Ctrl+D` |
| 삭제 | `Delete` / `Backspace` |
| 인라인 스타일 초기화 | `Alt+Delete` |
| 그룹으로 묶기 / 풀기 | `Ctrl+G` / `Ctrl+Shift+G` |

여러 개를 선택하고 드래그하면 함께 움직입니다. 부모와 자식을 같이 선택했을 때는 드래그한 요소 기준으로 한 번만 이동합니다.

## 5. 속성 패널 (오른쪽)

요소를 선택하면 오른쪽에 나타납니다. 여러 개 선택 시 "N개 선택"으로 표시되고 전부에 적용됩니다.

| 항목 | 내용 |
| --- | --- |
| 위치 X / Y | `position`이 static이면 비활성. 한 번 드래그하면 활성화 |
| 크기 W / H | 너비·높이 |
| 바깥 여백 / 안쪽 여백 | 상·우·하·좌 |
| 둥근 모서리, 투명도 | 투명도는 0~100% |
| 글꼴 크기 / 굵기 / 정렬 | 굵기 300~700 |
| 색상 | 글자색 / 배경색 / 테두리색 (색상 선택기 + hex) |

입력 방법: 숫자 입력 후 `Enter`, `↑↓` ±1 (`Shift` ±10), 라벨을 좌우로 드래그(스크럽), 슬라이더 드래그, ▲▼ 버튼. 값을 만지는 동안 페이지에 무엇이 바뀌는지 표시됩니다(너비는 치수선, 여백은 색 띠, 글꼴은 텍스트 영역 강조). 모든 변경은 실시간으로 적용되고 손을 떼는 순간 한 단계로 기록됩니다.

## 6. 텍스트 편집과 텍스트 툴바

- 아무 글자나 **더블클릭**하면 바로 편집됩니다(`e` 도구). `Esc`로 편집 종료.
- 텍스트가 있는 요소를 선택하면 위에 **미니 툴바**가 뜹니다: 굵게 / 기울임 / 밑줄 / 글꼴 크기(슬라이더·▲▼·숫자) / 글꼴 / 글자색 / 배경색 / 좌·중·우 정렬. "더보기"에 줄 간격·자간·투명도.
- 편집 중 일부 글자만 드래그해 선택하고 툴바를 누르면 그 부분만 바뀝니다.
- 색상 버튼을 누르면 **이 페이지에서 쓰는 색상** 팔레트와 스포이드(페이지 아무 곳이나 클릭해 색 가져오기)가 뜹니다. 글꼴 목록도 페이지가 쓰는 글꼴이 먼저 나옵니다.
- 텍스트 내용 변경도 이력에 기록되어 AI 복사에 `- 텍스트: "전" → "후"`로 들어갑니다.

## 7. 도구 전환 (단축키 전용)

화면 왼쪽에 떠 있던 도구 툴바는 없앴습니다. 여백·글꼴·색상이 이미 속성 패널과 텍스트 툴바로 옮겨간 것처럼, 나머지 도구도 전부 단축키로만 전환합니다.

| 키 | 도구 | 하는 일 |
| --- | --- | --- |
| `l` | 선택 / 이동 (기본) | 클릭 선택, 드래그 이동, 핸들 크기 조절, 방향키 1px(`Shift` 10px) |
| `e` | 텍스트 | 글자 편집. 더블클릭과 같음 |
| `a` | 정렬 (Flex) | `방향키` 정렬, `Shift+←→` 배분, `Ctrl+↓/→` 방향 전환 |
| `v` | 순서 바꾸기 | `←→` 형제 사이 이동, `↑` 부모 밖으로, `↓` 자식 안으로 |
| `g` | 거리 측정 | 마우스를 올리면 정렬선·거리. 요소를 선택하고 다른 요소에 올리면 둘 사이 거리 |
| `c` | AI로 복사 | 클릭 = 복사, `Alt+클릭` = 이력 초기화. 현재 도구는 유지 |

숨은 고급 모드(단축키로만 진입, 버튼 없음): `m` 바깥 여백, `p` 안쪽 여백(`방향키` +, `Alt+방향키` −, `Ctrl+↑↓` 전체), `f` 글꼴(`↑↓` 크기, `←→` 자간, `Ctrl+↑↓` 굵기), `h` 색상(`←→` 채도, `↑↓` 밝기, `Ctrl+↑↓` 색상, `[ ]` 대상 전환).

**Alt+호버로 바로 거리 측정**: `g`로 도구를 바꾸지 않아도, 요소를 하나 이상 선택한 채 `Alt`를 누르고 다른 요소 위에 마우스를 올리면 즉시 거리가 표시됩니다. `Alt`를 떼면 사라집니다.

**오른쪽 패널로 통합**: 예전에 툴바 ⚙에 있던 설정(테마, 투명도, 패널 위치 초기화)과 **AI로 복사** 버튼은 오른쪽 패널 헤더로 옮겨왔습니다. 패널은 **속성 | 이력** 두 탭으로 전환하고, 헤더의 `⋮` 버튼으로 접었다 펼 수 있습니다(상태가 기억됩니다). `Ctrl+/`는 이제 툴바가 아니라 DesignPoke의 선택 기능 자체를 켜고 끕니다.

## 8. 되돌리기와 이력

| 동작 | 방법 |
| --- | --- |
| 실행 취소 / 다시 실행 | `Ctrl+Z` / `Ctrl+Shift+Z` (한 동작씩) |
| 이력 패널 | 화면에 항상 표시. 항목을 클릭하면 그 요소 선택 |
| 시점 미리보기 | 항목에 마우스를 올리면 그때 상태를 보여줌 (이력은 건드리지 않음) |
| 여기로 되돌리기 | 항목의 ⎌ 버튼 |
| 원본 보기 | 패널 상단 버튼을 누르고 있거나 `\` 키 토글 |
| 항목 개별 삭제 | 항목의 × 버튼 (이력에서만 제거) |
| 전체 초기화 | AI로 복사 버튼 `Alt+클릭` |

삭제한 요소도 이력에 남고 `Ctrl+Z`로 원래 자리에 복구됩니다.

## 9. 메모 (Ctrl+K)

- 요소를 선택하고 `Ctrl+K` → 입력창에 의도를 적고 `Enter`. AI 복사 문구의 해당 요소 항목에 `- 요청: "..."`로 들어갑니다.
- 선택 없이 `Ctrl+K` → 페이지 전체 요청. `## 요청` 섹션으로 들어갑니다.
- 이력 패널에서 ✎ 버튼으로 수정할 수 있습니다.

## 10. 스크린샷

| 동작 | 방법 |
| --- | --- |
| 화면 캡처 + 저장 | `Alt+S` (다운로드 폴더에 저장, 경로가 클립보드에 복사, 이력에 기록) |
| 이미지로 복사 | 이력 패널의 스크린샷 항목 → 이미지 복사 |
| 표시 스크린샷 복사 | 이력 패널 버튼. 변경한 요소에 빨간 번호 박스를 그려서 복사. 번호는 AI 복사 문구의 번호와 같음 |

캡처할 때 DesignPoke의 핸들·패널은 자동으로 숨겨집니다. 이미지 복사는 `https` 또는 `localhost`에서만 됩니다(일반 `http` 페이지는 안내 메시지만 표시).

## 12. 단축키 한눈에 보기

| 키 | 동작 |
| --- | --- |
| `Ctrl+Shift+D` | DesignPoke 켜기 / 끄기 |
| `Esc` | 선택 해제 → DesignPoke 끄기 |
| `Ctrl+Z` / `Ctrl+Shift+Z` | 실행 취소 / 다시 실행 |
| `Ctrl+K` | 메모 |
| `c` | AI로 복사 |
| `Alt+S` | 스크린샷 |
| `Shift+H` | 핸들 숨기기 |
| `\` | 원본 보기 토글 |
| `Ctrl+/` | DesignPoke 선택 기능 켜기/끄기 |
| `Ctrl+D` / `Delete` | 복제 / 삭제 |
| `Ctrl+Alt+C` / `Ctrl+Alt+V` | 스타일 복사 / 붙여넣기 |
| `l g m p a v e f h` | 도구 전환 |

Mac에서는 `Ctrl` 대신 `Cmd`, `Alt` 대신 `Option`입니다.

## 13. 개발자용

- 빌드: `npm install` → `npm run build:ext`
- 샌드박스: `npm start` 후 `http://localhost:3000` (app/index.html)
- 테스트: `npm run test:e2e` (puppeteer E2E 전체 + 확장 로드 테스트)
- 변경 기록: `CHANGELOG.md`
