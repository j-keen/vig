## 2026-09-24

- **목적**: 바이브 코딩 결과(랜덤한 AI 출력)를 페이지 위에서 직접 다듬어 AI에게 정확히 전달하는 도구. 캔바형 독립 웹앱(템플릿 사이트 빌더)은 **폐기**. 대안 갤러리는 "내 킷"의 변형으로 흡수.
- **다음 큰 기능 = 내 킷(개인 UI 라이브러리)**: 잘 나온 조각(버튼·카드·섹션)을 저장 → 다른 사이트에서 hover 미리보기/클릭 적용 → 이력 기록 → AI 전달.
  - 저장 포맷: HTML + 계산 스타일 + Tailwind 클래스 + 썸네일 (JSON). 소스 코드 연결 칸은 예약만.
  - 적용 규칙: "모양만 입히기"(작은 요소, 글자·링크 유지) / "통째로 교체"(섹션, 제목·본문·CTA·이미지 옮겨 담기). 요소 크기로 자동 판단 + 토글.
  - 저장 위치: PC 로컬 + JSON 내보내기/가져오기. 기본 킷(내장, 읽기 전용) / 내 킷 분리 → 판매 대비.
  - 변형 ◀▶ UI는 프로토타입을 보고 확정. 클라이언트(프레젠테이션) 모드는 2차.
- **폴리시 먼저**: 선택 유지, 패널 자유 이동, 테마/투명도, 툴바 6개로 통합, 배경색 힌트 수정 → 커밋 `2e3131c`.
- 툴바 통합 시 m/p/f/h 버튼은 숨기되 단축키는 유지(기존 테스트·고급 사용자 보호).
- 설정 저장: 확장에서는 chrome.storage(전역), 샌드박스는 localStorage 폴백.
