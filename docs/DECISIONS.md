## 2026-09-25

- **왼쪽 툴박스 폐기 → 오른쪽 사이드 패널 하나(속성 | 이력 탭)**. 사용자 판단: 왼쪽 도구 6개가 전부 다른 곳에서 이미 되거나 더 자연스러운 자리가 있음("예쁜 쓰레기").
  - 선택/이동 = 기본 상태, 텍스트 = 더블클릭(텍스트 툴바는 요소 근처에 그대로 뜸), 정렬(Flex)·순서 = 속성 패널 섹션, 거리 측정 = **Alt+호버**, AI 복사·⚙ = 패널 헤더.
  - 단축키(l/e/a/v/g/m/p/f/h/c)는 숨은 채로 유지.
- **속성 패널은 한 줄씩**: `라벨 · 짧은 게이지 · 작은 숫자칸`. 기존 두 줄(입력+게이지)이 너무 길다는 사용자 지적. ▲▼ 스테퍼 제거, 라벨 스크럽·방향키는 유지.
- 버전 표시 규칙: 사용자에게 보이는 변경마다 manifest/package 버전을 올리고 ⚙ 팝오버에 표시(1.2.0부터). 새로고침 여부를 버전으로 확인.
- 1.2.1 교훈: `hidden` 속성만 붙인 툴바 정리가 author CSS에 밀려 실제로는 적용되지 않았고, 테스트는 속성만 검사해 통과함. **UI 변경은 computed style/스크린샷으로 검증**한다(사용자 PC의 Chrome으로 스크린샷 확인 절차 도입).
- Chrome 공식 문서(코딩 에이전트로 확장 빌드)의 chrome-devtools MCP + modern-web-guidance 스킬 도입은 GO 대기.

## 2026-09-24

- **목적**: 바이브 코딩 결과(랜덤한 AI 출력)를 페이지 위에서 직접 다듬어 AI에게 정확히 전달하는 도구. 캔바형 독립 웹앱(템플릿 사이트 빌더)은 **폐기**. 대안 갤러리는 "내 킷"의 변형으로 흡수.
- **다음 큰 기능 = 내 킷(개인 UI 라이브러리)**: 잘 나온 조각(버튼·카드·섹션)을 저장 → 다른 사이트에서 hover 미리보기/클릭 적용 → 이력 기록 → AI 전달.
  - 저장 포맷: HTML + 계산 스타일 + Tailwind 클래스 + 썸네일 (JSON). 소스 코드 연결 칸은 예약만.
  - 적용 규칙: "모양만 입히기"(작은 요소, 글자·링크 유지) / "통째로 교체"(섹션, 제목·본문·CTA·이미지 옮겨 담기). 요소 크기로 자동 판단 + 토글.
  - 저장 위치: PC 로컬 + JSON 내보내기/가져오기. 기본 킷(내장, 읽기 전용) / 내 킷 분리 → 판매 대비.
  - 변형 ◀▶ UI는 프로토타입을 보고 확정. 클라이언트(프레젠테이션) 모드는 2차.
- **폴리시 먼저**: 선택 유지, 패널 자유 이동, 테마/투명도, 툴바 6개로 통합, 배경색 힌트 수정 → 커밋 `2e3131c`.
- 툴바 통합 시 m/p/f/h 버튼은 숨기되 단축키는 유지(기존 테스트·고급 사용자 보호).
- 설정 저장: 확장에서는 chrome.storage(전역), 샌드박스는 localStorage 폴백.
